# Studio illustrations (themed)

Each SVG uses only the two theme colours (and tints of them), so a theme only needs to swap them:

- `#C84C0E`: Primary 1 (orange). Highlights, accents, ticks.
- `#0B4B66`: Primary 2 (heading blue). Outlines, people, devices.

Light tints of these colours follow the same theme colour. Greys stay neutral.
