# Studio illustrations (themed)

Each SVG uses only the two theme colours and tints of them, so a theme only needs to swap them:

- `#C84C0E`: Primary 1 (orange). Accents, ticks, highlights. Tints: `#FBEEE8`, `#F2C3AB`.
- `#0B4B66`: Primary 2 (heading blue). Outlines and devices. Tints: `rgba(11, 75, 102, x)`.

Everything else is white. All are decorative (`aria-hidden` in the app).
